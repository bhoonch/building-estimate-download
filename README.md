# 빌딩매니저 견적서 — 설치 파일

건물관리 도급 견적서를 자동으로 만들어 주는 Windows 프로그램의 설치 파일 배포용 저장소입니다.

## 내려받기

**[최신 설치 파일 받기](https://github.com/bhoonch/building-estimate-download/releases/latest/download/BuildingManager-Estimate-Setup.exe)** (Windows 10 / 11, 64비트)

- 설치하면 체험판으로 시작합니다. 모든 기능을 쓸 수 있고, 견적서 출력에 워터마크가 표시됩니다.
- 라이선스 키를 프로그램의 대시보드 > 라이선스 칸에 등록하면 워터마크가 사라집니다.
- 라이선스 구매와 사용 안내: https://bdmg.co.kr

이전 버전은 [Releases](https://github.com/bhoonch/building-estimate-download/releases)에서 받을 수 있습니다.
